## 🇬🇧 English

This is my public journey from beginner to cybersecurity professional.

I will document what I learn, the labs I complete, security research I conduct, and detection rules I create.

**Learn → Practice → Document → Publish → Improve → Get Hired.**

My ultimate goal is to get my first job in cybersecurity while building a public knowledge base that can help other beginners follow the same path.
